# Atlas Roadmap

## For Beta 2
- Investigate and move shaders to slang *M1*
- Add better support for Vulkan in Opal *M2*
- Move Photon to a spectral renderer *M3*
- Add dispersion, volumes and accurate caustics to Photon *M4*
- Add iridescence and SSS to Photon *M5*
- Introduce denoisinc and ReSTIR DI to Atlas *M6*
- Fix PBR SSR and DDGI isssues and add transmission, refraction and fresnel to the PBR pipeline *M7*
- Add geometry physical displacement and tessellation *M8*
- Add Bezel Jolt softbodies and cloth simulation *M9*
- Add a shader customization and procedural material system *M10*
- Implement an animation system for Atlas *M11*
